# 🌤 Weather App

A simple and responsive weather application built using HTML, CSS, and JavaScript.  
This app fetches real-time weather data from a public REST API and displays it dynamically on the webpage.

---

## 🚀 Features

- 🔍 Search weather by city name
- 🌡 Shows temperature
- ☁ Displays weather condition
- 💧 Shows humidity
- 🌬 Displays wind speed
- 🕒 Shows local time
- 🌤 Dynamic weather icons
- 🎨 Dynamic background based on weather
- ⌨ Press Enter to search
- ⚠ Error handling
- ⏳ Loading state
- 📱 Responsive and modern UI

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- WeatherAPI

---

## 🌐 API Used

This project uses the WeatherAPI public REST API.

🔗 https://www.weatherapi.com/
